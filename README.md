## How to Deploy on GitHub Pages

1. Push all files to your GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, select **Deploy from a branch**
4. Set branch to `main` and folder to `/ (root)`
5. Click **Save**
6. Your site will be live at `https://yourusername.github.io/your-repo-name` within a minute

---

## How to Upload Files to This Repo

> ⚠️ Do **not** upload the zip file directly. GitHub needs the actual files.

**Option A — GitHub website**
1. Extract/unzip the downloaded file on your computer
2. Open the extracted `gis-portfolio` folder
3. Go to your GitHub repo → click **Add file → Upload files**
4. Go *inside* the `gis-portfolio` folder and select **all the contents** (not the folder itself)
5. Drag everything into the GitHub upload area
6. Write a commit message and click **Commit changes**

**Option B — GitHub Desktop (recommended for large uploads)**
1. Install [GitHub Desktop](https://desktop.github.com)
2. Clone your repository to your computer
3. Delete any existing files inside the local folder
4. Paste in all the contents from the extracted `gis-portfolio` folder
5. GitHub Desktop will detect the changes automatically
6. Click **Commit to main** → then **Push origin**

## Site Features

- **Sticky header** — name and info stays visible while scrolling
- **3 interactive slideshows** — SWAT, Hydroclimatic, and LULC maps with smooth directional transitions and 5-second auto-advance
- **Project grids** — 2-column layout organised by project name and analysis type
- **Lightbox viewer** — click any map to open full screen; click again to zoom 2×
- **Keyboard shortcuts** — `←` `→` to navigate slides, `Esc` to close lightbox
